# Arquitetura — Automation Control Tower

> Documento vivo. Atualize a cada decisão técnica relevante.

## 1. Objetivo

Observabilidade das automações: execuções, falhas, retentativas e incidentes.

## 2. Componentes

| Componente | Responsabilidade |
|---|---|
| API (FastAPI) | Recebe eventos padronizados dos outros projetos |
| PostgreSQL | Execuções, erros, retentativas e incidentes |
| n8n | Alertas, escalonamento e rotinas de verificação |
| IA | Resumo e agrupamento de incidentes |
